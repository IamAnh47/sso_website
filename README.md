# Smart Study Space (SSO)

Website quản lý đặt phòng.


## Setup and Installation

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation Steps

1. Clone the repository:
   ```
   git clone https://github.com/IamAnh47/sso
   cd sso
   ```

2. Install dependencies:
   ```
   npm install
   ```
3. Initializing the database:
   ```
   npm run init
   ```
4. Run server:
   ```
   npm start
   ```
